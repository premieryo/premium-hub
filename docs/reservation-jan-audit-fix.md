# 予約説明とJAN監査理由の修正

基準: PR #41 d58c7c7。PCの実API監査で、説明の予約文言を検査せず通過し、マスタJANなしでも監査理由に「JAN一致」と出ることが判明した。

## 方針

- タイトル・見出しに加え、商品説明の予約文言を確認する。
- 一般的な予約注意書きか当該出品の条件か自動で確定できないため、説明に予約が残る出品は保守的に保留する。一般注意書きを持つ正常商品も対象となり得る。価格の大小を除外根拠にしない。
- JANはマスタ未設定、未確認、一致、不一致を別フィールドで報告する。API JANがある場合はタイトルより優先し、タイトルの部分的な数字一致を根拠にしない。
- 公式JANの追加や本番データ変更は行わない。
